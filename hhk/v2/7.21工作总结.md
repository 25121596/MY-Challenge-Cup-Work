## 二、自检中发现并解决的问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 断网测试 off-by-one (14/15) | `InferenceWorker.stats["total"]` 在循环开头+1，但 results 在推理结束后才 append → drain 竞态 | 改为等待 `len(worker.results) >= expected` |
| Windows 连接不存在端口要 ~2s | OS 级 SYN 重试（非即时 RST），20条×2s=40s 超 drain 预算 | 引入 `BrokenEndpoint`（accept 即 close），毫秒级失败 |
| 3 个 schema JSON "不合法" | 它们是 JSONC 文档（含 `//` 注释），运行时从不被 json.load | 修正断言为"存在性检查"，仅 task_types.json 要求严格 JSON |
| parse_short_decision JSON 路径被遮蔽 | 单数字正则 `\b(\d)\b` 先命中 `"c":2` 中的 2 | 无害（GBNF 保证裸数字输出），标注为已知行为，未改产品代码 |
